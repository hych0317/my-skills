# Output Format Examples

## Chapters

```text
00:00 Introduction
02:15 Background and motivation
05:30 Main approach
12:45 Results and evaluation
18:20 Limitations and future work
21:00 Q&A
```

## Summary

Use two layers and keep them separate.

### Part 1: Basic Info

Use brief factual lines. Include only fields available from the source or metadata.

```text
标题：视频标题
简介：一句话说明主题或主张
背景：一句话交代讨论对象或范围
发布者：频道 / UP 主
时长：视频时长
```

### Part 2: Content Summary

Write calm, neutral, fact-focused prose. Use headings for medium and long videos. Do not force every video into the same number of paragraphs.

Short video:

```text
第二部分：内容总结

用三至五个主题段落依次说明背景、核心观点、关键证据或步骤，以及结论。
```

Long video:

```text
第二部分：内容总结

### 执行摘要
概括视频的中心问题、主要结论和整体方法。

### 00:00–09:40 背景与问题定义
说明该时间段提出的新信息、论点和必要例子。

### 09:40–18:10 方法与案例
保留方法细节、操作步骤、约束和案例结果。

（继续覆盖所有实质性时间段）

### 核心结论与可执行项
汇总结论、决策、限制和可复用做法。
```

## Coverage Ledger

Create this as working notes for long-form videos. It need not appear in the final answer unless useful.

```text
00:00–09:40  背景与问题定义  covered
09:40–18:10  方法与案例      covered
18:10–24:00  重复演示        merged as repetition into 09:40–18:10
24:00–25:20  片尾与致谢      non-substantive
```

## Chapter Summaries

```text
## 00:00 Introduction (2 min)
The speaker introduces the topic of X and explains why it matters for Y.

## 02:15 Background (3 min)
A review of prior work, covering approaches A, B, and C.
```

## Thread (Twitter/X)

```text
1/ The video examines [topic]. Here are the key takeaways:
2/ First insight: [point]. This matters because [reason].
3/ The surprising part: [finding and evidence].
4/ Practical takeaway: [actionable advice].
5/ Full video: [URL]
```

## Blog Post

Include a title, introduction, H2 sections for every major topic, timestamped quotes when available, and a conclusion.

## Quotes

```text
"The most important thing is not the model size, but the data quality." — 05:32
```
