# my-skills

这是一个个人 GitHub Skills 仓库，用来整理和维护可复用的技能（skills）与提示词（prompts）。

## 仓库内容

当前仓库包含的内容示例：

- `grill-skill/`：用于在执行前澄清需求、确认边界的 Skill
- `prompt-builder/`：用于生成结构化需求契约或 Session Handoff 的 Skill
- `media/video-summary/`：用于视频转录与总结的 Skill

## 适用场景

- 需求确认与澄清
- 提示词结构化编写
- 视频内容转录、总结与分段分析
- 其他可复用的 AI 工作流整理
